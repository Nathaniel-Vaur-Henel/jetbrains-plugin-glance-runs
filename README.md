# GlanceRuns

A mosaic run manager for IntelliJ Platform IDEs: watch all your long-running
commands at a glance, without keeping a full-size console open for each one.

- JetBrains Marketplace listing: https://plugins.jetbrains.com/plugin/36221-glanceruns/

## About this repository

GlanceRuns' source code is maintained in a private repository. This public
repository exists **only to host Issues**, so that users can report bugs or
suggest features without needing access to the source.

There is no code here, and pull requests won't be reviewed — please open an
Issue instead.

## Reporting a bug

Use the "Bug report" issue template and include:
- GlanceRuns version
- IDE name and version (e.g. IntelliJ IDEA 2025.3.5)
- OS
- Steps to reproduce
- Expected vs. actual behavior

## Suggesting a feature

Use the "Feature request" template. Check the plugin's changelog on the
Marketplace page first — your idea might already be planned.

## Language

Issues in English or French are both welcome.
